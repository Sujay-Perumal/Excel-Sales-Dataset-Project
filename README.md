## 📁 Project Summary

This project analyzes retail sales data using **Microsoft Excel**.  
It demonstrates practical data analytics skills including:

- Data cleaning & structuring  
- Lookup and conditional functions  
- PivotTables for summarization  
- PivotCharts for visualization  
- Interactive dashboard using slicers  

The final workbook includes a fully functional analytics dashboard built entirely in Excel.

---

## 🧰 Core Excel Skills Demonstrated

### 🔢 **Functions**

| Function       | Purpose                                            |
|----------------|----------------------------------------------------|
| **SUM()**      | Calculate totals (sales, quantities, revenue)      |
| **SUMIF()**    | Conditional totals by region, category, or date    |
| **AVERAGE()**  | Measure average sales                              | 
| **AVERAGEIF()**| Conditional averages                               | 
| **VLOOKUP()**  | Retrieve product/customer information              | 
| **Formatting** | Clean, readable, professional structure            |

---

### 📈 **PivotTables & PivotCharts**

PivotTables were used to generate insights such as:

- Sales by region  
- Product category performance  
- Monthly trends  
- Best-selling products  
- Customer segmentation  

PivotCharts transformed these insights into visual, interactive elements.

---

### 🎛️ **Dashboard Interactivity**

The dashboard includes slicers for:

- Product Category  
- Gender  
- Generation  

These slicers make the dashboard dynamic and user-friendly, enabling quick comparisons and deep dives.
